# New Feature Requests

Ordered by priority (highest impact / biggest current gap first).
Mark as done when the feature is implemented.

- [x] add a license — chose **AGPLv3** (confirmed with the user): free use/modification/redistribution for anyone, including commercially, but any distributed or network-served (SaaS) version must keep its source open under the same terms — it can never be relicensed closed-source. Added `LICENSE` (canonical FSF text), `license` fields in `package.json`/`Cargo.toml`, and a License section in `README.md`. Note: a literal "no one can ever sell it" clause isn't compatible with any OSI-approved open-source license (all permit commercial redistribution); AGPL's copyleft achieves the practical effect (no proprietary lock-in, any buyer can redistribute free) without that contradiction.
- [x] GPG/SSH commit-signing setup wizard — new `signing.rs` backend + `Settings → Git → Commit Signing` (`SigningWizard.tsx`). SSH path: generate a new ed25519 key (or pick an existing pubkey) and it's wired via `gpg.format=ssh` + `user.signingkey` + `commit.gpgsign`; GPG path: import one of the machine's existing secret keys or generate a new one (only offered if `gpg` is on PATH), same wiring with `gpg.format=openpgp`. Scope (global/repo) follows the existing Git identity scope selector.
- [x] Offline-mode indicator when network-dependent actions (fetch/push/PRs) can't reach the remote — new `useNetworkStore`: tracks the browser's online/offline events as a baseline, and additionally flips to offline when a fetch/pull/push/LFS sync or PR-list load fails with a connectivity-shaped error (DNS/connection/timeout, distinguished from git-level errors like auth or conflicts); clears on the next success. Shown as a small "Offline" badge in the toolbar.
- [x] make sure for file icons we are using https://react-symbols.pheralb.dev/ (npm i @react-symbols/icons) — replaced the old hand-rolled extension→lucide-icon map (`lib/file-icons.ts`) with `@react-symbols/icons`'s `FileIcon` util (`lib/file-icons.tsx`, `autoAssign` on for special filenames like `package.json`/`Dockerfile`), used in `FileList.tsx`.
